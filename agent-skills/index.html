🤖 Agent Skills

AI 에이전트가 읽고 활용하는 재사용 가능한 능력 팩입니다. SKILL.md 파일 하나에 절차적 지식(워크플로우, 사용법, 주의사항)을 담아두면, 에이전트가 필요할 때 읽어서 그대로 실행합니다. 한 번 만든 자동화는 계속 재사용됩니다.

📦 설치 방법

Google 공식 스킬 라이브러리 전체 목록 보기:

npx skills add google-gemini/gemini-skills --list

특정 스킬만 설치:

npx skills add google-gemini/gemini-skills --skill gemini-api-dev --yes

출처: github.com/google-gemini/gemini-skills (Apache-2.0)

🌐 google-gemini/gemini-skills

Google이 공개한 공식 스킬 3종 — npx skills add 한 줄로 설치됩니다.

gemini-api-dev

npx skills add ... --skill gemini-api-dev

Gemini API로 코드 짤 때 읽는 스킬. 텍스트 생성, 멀티턴 채팅, 이미지·영상·TTS 생성, 함수 호출(Function Calling), 구조화 출력, 구 generateContent API 마이그레이션까지. Python(google-genai)·TypeScript(@google/genai) SDK 사용법과 최신 모델 목록 포함.

gemini-live-api-dev

npx skills add ... --skill gemini-live-api-dev

실시간 양방향 스트리밍 앱용 스킬. Gemini Live API의 WebSocket 오디오·영상·텍스트 스트리밍, 음성 감지(VAD), 백그라운드 추론, 비동기 함수 호출, 세션 관리, 실시간 자막·번역 구현 가이드.

gemini-omni-flash-api

npx skills add ... --skill gemini-omni-flash-api

생성형 영상 편집 스킬. 텍스트→영상, 이미지 참조 영상 생성, 첫/마지막 프레임 전환, 영상 확장(최대 40초), 턴 단위 영상 편집 워크플로우와 ffmpeg 전처리 가이드.

✨ 직접 만든 스킬

실제 매일 돌리고 있는 자동화 파이프라인을 SKILL.md로 패키징했습니다.

shorts-pipeline

매일 3개 영상 자동 제작

유튜브 쇼츠 / 인스타그램 릴스 일일 제작 파이프라인. plan → 이미지 생성 → build 3단계로 1080×1920 세로 영상(약 30초)을 만듭니다. 영어 회화·웃긴 짤·기네스북 3개 카테고리를 요일별로 순환하고, TTS 내레이션 + 자막 오버레이 + Ken Burns 줌 효과를 ffmpeg로 자동 조립합니다.

1080×1920 · 25fps 3 segments × 10s TTS + 자막 주제 중복 방지
