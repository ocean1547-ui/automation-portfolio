# 마케팅 실행 가이드 — 어디에, 어떻게 올리는지

## 1. Fiverr 상품 등록 (가장 먼저)

**어디:** https://www.fiverr.com → 가입 → 오른쪽 위 프로필 → Selling → Create a Gig

**어떻게 (상품 1개당 반복):**
1. Gig title에 아래 제목 복붙
2. Category: **Programming & Tech** → Subcategory: **Data** (엑셀/스크래핑) 또는 **Utilities** (자동화)
3. Description에 아래 설명 복붙
4. Pricing: Basic $30 / Standard $70 / Premium $150
5. Requirements: "샘플 파일 1개 또는 원하는 결과 설명" 이라고 적기
6. 썸네일: GitHub 데모 GIF 첫 화면 캡처해서 올리기

**상품 1 — 엑셀 자동화**
- 제목: `I will clean and automate your messy Excel spreadsheets with Python`
- 설명: `Drowning in messy spreadsheets? I turn chaotic Excel/CSV files into clean, analysis-ready data. Duplicates removed, dates and prices standardized, plus a clear summary report. You also get a reusable script to run it yourself next month. Working demo: https://github.com/ocean1547-ui/automation-portfolio/tree/main/excel-cleaner`

**상품 2 — 가격 추적기**
- 제목: `I will build a price tracker that alerts you when prices drop`
- 설명: `Never overpay again. I build a custom tracker that watches any product page and notifies you the moment the price hits your target. Includes price history log and daily auto-check setup. Working demo: https://github.com/ocean1547-ui/automation-portfolio/tree/main/price-tracker`

**상품 3 — 단체 메일 자동화**
- 제목: `I will set up automated personalized bulk emails for your business`
- 설명: `Send 100 personalized emails in the time it takes to send one. Safe setup with dry-run preview before anything is sent — zero accidents. Includes Gmail/Outlook setup guide. Working demo: https://github.com/ocean1547-ui/automation-portfolio/tree/main/email-sender`

## 2. Upwork 일감 찾기 (프로필 완성 후)

**어디:** https://www.upwork.com → Find Work → 검색

**검색어 (돌아가며 검색):**
- `excel automation`, `web scraping`, `data cleaning`, `python script`, `google sheets automation`

**필터:** Payment verified 체크 + $30 이상

**어떻게:** 마음에 드는 공고 3~5개에 `marketing/proposal_template.md` 형식으로 제안서 보내기.
첫 2주는 **매일 30분, 제안서 3개**가 목표.
