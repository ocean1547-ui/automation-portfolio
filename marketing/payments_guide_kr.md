# 외주 대금 받는 법 (Upwork / Fiverr)

## Upwork

1. 클라이언트가 일 시작 전 대금을 **에스크로(escrow)**에 예치
2. 일 완료 → 클라이언트 승인 → 대금이 내 잔액에 들어옴
3. **수수료 10%** 제외 (예: $100 → $90 수령)
4. **5일 보안 기간** 후 출금 가능
5. 출금 방법: 캐나다 은행 직접 입금, Payoneer, PayPal
6. 첫 출금까지 보통 **약 2주** 소요

## Fiverr

1. 주문 완료 → 대금 확정
2. **수수료 20%** 제외 (예: $100 → $80 수령)
3. 신규 셀러는 **14일 정산 대기** 후 출금 가능
4. 출금 방법: PayPal, 은행 입금, Payoneer

## 꼭 알아둘 것

- **플랫폼 밖에서 일하지 마세요.** 에스크로/보호 없이 일하면 먹튀 위험 100%.
- "선입금 보내줄테니 먼저 ○○해달라"는 100% 사기.
- 캐나다에서는 외주 소득도 **자영업 소득으로 CRA에 신고**해야 해요.
  (연말에 T2125 양식, 간단한 장부만 있으면 됨)
- Payoneer 계정은 미리 만들어두면 출금이 빨라요.

## 현실적인 첫 달 목표

- 첫 1~2건: $30~80짜리 작은 일로 별점 5개 쌓기
- 리뷰 5개 이후: 단가 인상 ($50/hr 이상)
- 목표: 월 $300~500부터 시작해서 점차 확대
