# Proposal Template (Upwork / direct outreach)

Subject: I can automate this for you — here's exactly how

Hi [name],

I read your posting carefully. Here's how I'd solve it:

**1. What I'll build**
[1–2 sentences: e.g. "A Python script that reads your daily sales CSV,
removes duplicates, standardizes the formats, and emails you a clean
summary every morning."]

**2. How long it takes**
[Realistic estimate, e.g. "2–3 days including testing."]

**3. Proof I can do it**
I built something very similar — you can see it running here:
[GitHub link to the relevant project + demo GIF]

**4. What I need from you**
- [e.g. one sample file, the website URL, ...]

**5. Price**
Fixed price: $[X] — includes [revisions/support terms].

Happy to jump on a quick call if that's easier.

Best,
James
[Upwork profile link]

---

## Tips
- Always reference THEIR specific problem in the first 2 lines.
- Link the matching demo GIF — it beats 100 words of promises.
- First 5 proposals: keep prices low, optimize for 5-star reviews.
- Reply within a few hours — speed wins jobs.
- Never work off-platform in the beginning (no payment protection).
