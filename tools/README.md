# tools/

Helper scripts used to generate the animated demo GIFs and intro videos
shown in each project's README. They are not part of the projects
themselves — just the tooling behind the demos.

| Script | What it does |
|---|---|
| `make_demo_gif.py` | Records a terminal run and renders it as an animated GIF |
| `make_demo_gif2.py` | Variant with different styling for a second batch of demos |
| `make_intro_video.py` | Assembles short intro videos for the portfolio projects |

Run from the repo root, e.g. `python tools/make_demo_gif.py`.
